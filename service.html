Service

브랜드의 단계와 목표에 맞춰 — 포지셔닝부터 제작 범위, 4단계 서비스 구성까지 BlinkDesign이 제공하는 웹디자인 서비스를 정리했습니다.

Approach

  • 01

    디자인 감도를 갖춘 웹사이트 제작

    단순히 정보를 나열하는 사이트가 아니라, 톤·여백·디테일까지 챙긴 화면을 만듭니다.

  • 02

    레퍼런스 기반의 빠른 방향성 구현

    처음부터 모든 것을 새로 그리지 않습니다. 좋은 레퍼런스를 함께 정리해, 결정의 속도와 결과물의 완성도를 동시에 끌어올립니다.

  • 03

    브랜드 분위기에 맞는 랜딩페이지·홈페이지 제작

    같은 구조라도 브랜드에 따라 다른 인상이 됩니다. 톤과 무드까지 옷을 맞춰 입히듯 다듬습니다.

  • 04

    배포와 도메인 연결까지 가능한 원스톱 진행

    디자인만, 디자인+구축, 배포까지 — 필요한 만큼만 골라 한 호흡으로 진행합니다.

제작 범위

어떤 종류의 웹사이트를 만드는지, 그리고 어떤 기능까지 다룰 수 있는지 안내합니다.

  • 이벤트/프로모션 페이지
  • 개인 포트폴리오 사이트
  • 소규모 병원/클리닉/스튜디오 홈페이지
  • 상담 신청용 웹페이지

  • 상담 신청 폼
  • 이메일 자동 발송 연동

서비스 구성

  • 01

    디자인만 필요한 경우

    Figma 디자인 파일 또는 HTML/CSS 정적 파일로 정리해 전달합니다. 자체 개발팀이 있거나, 다른 곳에서 구축할 예정인 경우에 적합합니다.

    포함 사항
    • 메인 디자인
    • 반응형 기준 디자인
    • 섹션 구성
    • CTA 구조
    • 기본 문구 정리
    • 이미지/아이콘 방향성
    납품 형태
    • Figma 파일
    • HTML/CSS/JS 파일
    • 이미지 에셋
    • 간단한 사용 가이드
  • 02

    디자인 + 웹 구축

    디자인 방향 설정부터 HTML 기반 웹사이트 구축까지 한 호흡으로 진행합니다.

    포함 사항
    • 페이지 구조 설계
    • 디자인 제작
    • 반응형 웹 구현
    • 기본 인터랙션
    • 문의 폼 구현
    • 기본 SEO 메타 태그
    • 브라우저 확인
    • 파일 전달
  • 03

    디자인 + 구축 + 배포

    웹사이트 제작 후 Netlify를 통해 실제 접속 가능한 상태로 배포하고, 보유한 도메인을 연결합니다.

    포함 사항
    • HTML/CSS/JS 구축
    • Netlify 배포
    • 도메인 연결
    • SSL 적용
    • 기본 접속 테스트
    • 문의 폼 또는 외부 앱 연동
  • 04

    유지보수 / 관리 별도 비용

    배포 이후 도메인·호스팅 상태 점검과 간단한 콘텐츠 수정을 월 단위로 지원합니다. 별도 비용으로 구분해 운영합니다.

    포함 가능
    • 도메인 연결 상태 확인
    • Netlify 배포 관리
    • 텍스트 수정
    • 이미지 교체
    • 버튼 링크 수정
    • 문의 폼 연결 확인
    • 월 1~2회 간단 수정
    제외 항목
    • 새 페이지 추가
    • 전체 디자인 변경
    • 대규모 콘텐츠 수정
    • 기능 추가 개발
    • 브랜드 리뉴얼
    • 복잡한 외부 서비스 연동
