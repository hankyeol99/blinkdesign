Service

디자인부터 구축, 배포까지 한번에 일관되게 진행합니다. 필요한 단계까지만 선택할 수 있고, 배포 이후 운영은 월 단위로 별도 지원합니다.

Approach

  • 01

    레퍼런스로 방향을 먼저 좁힙니다

    문의를 받으면 3~5개의 레퍼런스를 정리해 먼저 전달합니다. 톤·구조·인터랙션 방향을 합의한 뒤 시안에 들어가기 때문에, 보통 1~2회의 수정 안에서 디자인이 확정됩니다.

  • 02

    디자인과 구축을 한 사람이 진행

    Figma 디자인부터 HTML/CSS 구축까지 같은 사람이 다룹니다. 디자인에서 결정한 간격·타이포·인터랙션이 구현 단계에서 흐트러지지 않고, 핸드오프 과정에서 발생하는 추가 수정 비용이 없습니다.

  • 03

    배포와 도메인 연결까지 가능한 원스톱 진행

    디자인, 구축, 배포, 도메인 연결까지 지원하며 필요한 만큼만 진행할 수 있습니다.

제작 범위

서비스 구성

  • 01

    디자인만 필요한 경우 평균 1~2주

    Figma 디자인 파일 또는 HTML/CSS 정적 파일로 정리해 전달. 자체 개발팀이 있거나, 다른 곳에서 구축 예정인 경우에 적합

    포함 사항
    • 메인 디자인
    • 반응형 기준 디자인
    • 섹션 구성
    • CTA 구조
    • 기본 문구 정리
    • 이미지/아이콘 방향성
    납품 형태
    • Figma 파일
    • HTML/CSS/JS 파일
    • 이미지 에셋
    • 간단한 사용 가이드
  • 02

    디자인 + 웹 구축 평균 2~3주

    디자인 방향 설정 구조 정리, HTML 기반 웹사이트 구축까지 한번에 진행

    포함 사항
    • 페이지 구조 설계
    • 디자인 제작
    • 반응형 웹 구현
    • hover · scroll fade-in 등 기본 인터랙션
    • 문의 폼 구현
    • 기본 SEO 메타 태그
    • 브라우저 확인
    • 파일 전달
    납품물
    • HTML/CSS/JS 파일
    • 이미지 에셋
    • Figma 디자인 원본
    • 간단한 사용 가이드
  • 03

    디자인 + 구축 + 배포 평균 2~3주 + 배포 1일

    웹사이트 제작 후 실제 접속 가능한 상태로 배포하고, 도메인 연결(커스텀 도메인 구매시 별도 비용)

    포함 사항
    • HTML/CSS/JS 구축
    • Cloudflare 배포
    • 도메인 연결
    • SSL 적용
    • 기본 접속 테스트
    • 문의 폼 + 외부 앱 최대 2개 연동 (Google Form, Channel Talk 등)
    납품물
    • 실서비스 URL
    • 도메인/SSL 설정 완료
    • 관리자 인계 가이드
  • 04

    유지보수 / 관리 월 50,000원 부터

    배포 이후 도메인·호스팅 상태 점검과 간단한 콘텐츠 수정을 월 단위로 지원. 별도 비용으로 구분하여 운영

    포함 가능
    • 도메인 연결 상태 확인
    • Cloudflare 배포 관리
    • 텍스트 수정
    • 이미지 교체
    • 버튼 링크 수정
    • 문의 폼 연결 확인
    • 월 텍스트·이미지·링크 수정 최대 3건
    제외 항목
    • 새 페이지 추가
    • 전체 디자인 변경
    • 대규모 콘텐츠 수정
    • 기능 추가 개발
    • 브랜드 리뉴얼
    • 복잡한 외부 서비스 연동

유지보수 플랜

배포 이후 사이트 운영을 함께 챙기는 월 단위 플랜. 필요한 범위에 맞춰 골라 진행할 수 있습니다.

  • 01

    베이직 월 5~10만원

    가동 보장 + 분기 1~2회 소규모 수정. 사이트가 정상 동작하는지 점검하고, 작은 텍스트·이미지 수정 정도만 함께 진행

  • 02

    스탠다드 월 15~25만원

    월 1~2회 콘텐츠 업데이트 + 백업 + 모니터링. 콘텐츠를 정기적으로 갱신해야 하거나, 사이트 안정성을 적극적으로 챙겨야 하는 경우에 적합

  • 03

    프리미엄 월 30~50만원

    디자인 수정 + SEO + 분석 리포트. 디자인을 지속적으로 다듬고 SEO·트래픽 데이터까지 함께 보면서 성장시키는 단계

* 추가 작업은 시간당 7~15만원으로 별도 청구됩니다.
